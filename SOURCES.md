## Version distinctions

- Taste entry point describes tasteskill 2.5.1.
- Impeccable package/skill metadata is 4.10.0; its bundled wrapper engine version is 0.1.27.
- img2threejs SKILL.md identifies 2.0.1, while package.json identifies its npm wrapper as 0.2.0. These are not interchangeable version pins.
- Playwright CLI package.json identifies @playwright/cli 0.1.25. Its dependency versions are separate from browser selection.

Use the full source commits in sources.lock.json as the reproducibility keys for this kit, rather than combining these different version numbers.
