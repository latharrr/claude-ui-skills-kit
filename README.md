# claude-ui-skills-kit

UI and motion skills for Claude.

## Skills

| Skill | What it does |
|---|---|
| [`living-scroll-motion`](skills/living-scroll-motion/SKILL.md) | Adds immersive scroll-driven motion to any website: smooth scroll, masked text reveals, pinned scenes, planet-wipe colour transitions, a 3D glass-shard layer and shard formations. Has Lite, Standard and Full tiers and works in vanilla, React/Next, Vue, Astro and Svelte. |

## Install

**Claude Code (personal):**
```bash
git clone https://github.com/latharrr/claude-ui-skills-kit
cp -r claude-ui-skills-kit/skills/living-scroll-motion ~/.claude/skills/
```

**Claude Code (one project):** copy the skill folder into `<project>/.claude/skills/`.

**Claude.ai:** zip `skills/living-scroll-motion` and upload it under Settings → Capabilities → Skills.
